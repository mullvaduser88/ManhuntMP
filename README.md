## English

ManhuntMP is a fan-made mod that lets you play the Manhunt story **together with up to 3 players online** through Steam.

### Features
- **PLAY ONLINE** in the main menu: Steam lobby for up to 3 players, friend invites, ping
- The host picks a scene, everyone loads it
- Other players are shown as Cash, with their weapons in hand, on the back and on the belt
- Shared hunters: they move the same for everyone and hunt whoever is closest to them
- Shared kills, shots, thrown bricks and bottles, picked-up items
- Shared levers, doors, gates, cutscene triggers
- Teammates on the radar, names above their heads
- Everyone plays on the host's save

### Requirements
- **Manhunt bought on Steam** (every player needs their own copy)
- Steam running and logged in
- Windows 10 or 11
- **Everyone must have the same version of the mod** (the launcher takes care of this)

### Install
1. Download **ManhuntMP_Launcher.exe** from the [latest release](../../releases/latest).
2. Run it and allow administrator access. Windows may say "Windows protected your PC": click **More info → Run anyway**.
3. The launcher finds Manhunt by itself (or press **Browse** and pick the folder with `manhunt.exe`).
4. Press **INSTALL**, then **PLAY**.

Paste the update link from the release notes once: after that the launcher checks for updates every time it starts. Original game files are backed up and restored by **UNINSTALL**.

### How to play together
- **Host:** main menu → **PLAY ONLINE → CREATE LOBBY → INVITE FRIENDS**, then **START GAME** and pick a scene.
- **Friends:** accept the invite in the Steam overlay (**Shift+Tab**) and wait in the main menu.
- Guests appear 15 seconds after the host (the second guest after 30 seconds), so nobody spawns inside each other.
- While the mod is running, Steam may show you as playing "Spacewar". That's normal: the mod uses Valve's free test app for networking.

### Reporting bugs
Send `ManhuntMP.log` from the game folder (from every player, if you can) and a short video to the Telegram channel.

## Русский

ManhuntMP — фанатский мод, который позволяет проходить сюжет Manhunt **вместе, до 3 игроков по сети** через Steam.

### Возможности
- **PLAY ONLINE** в главном меню: лобби Steam до 3 игроков, приглашения друзей, пинг
- Хост выбирает сцену — она загружается у всех
- Другие игроки видны как Кэш, с оружием в руках, на спине и на поясе
- Общие охотники: двигаются одинаково у всех и охотятся на того, кто к ним ближе
- Общие убийства, выстрелы, брошенные кирпичи и бутылки, подобранные предметы
- Общие рычаги, двери, ворота, триггеры катсцен
- Напарники на радаре, ники над головой
- Все играют на сохранении хоста

### Что нужно
- **Manhunt, купленный в Steam** (у каждого игрока своя копия)
- Запущенный Steam
- Windows 10 или 11
- **У всех должна быть одна и та же версия мода** (лаунчер следит за этим сам)

### Установка
1. Скачайте **ManhuntMP_Launcher.exe** из [последнего релиза](../../releases/latest).
2. Запустите и разрешите права администратора. Если Windows напишет «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**.
3. Лаунчер сам найдёт Manhunt (или нажмите **Browse** и выберите папку с `manhunt.exe`).
4. Нажмите **INSTALL**, затем **PLAY**.

Один раз вставьте ссылку для обновлений из описания релиза: после этого лаунчер проверяет обновления при каждом запуске. Оригинальные файлы игры сохраняются, кнопка **UNINSTALL** возвращает их обратно.

### Как играть вместе
- **Хост:** главное меню → **PLAY ONLINE → CREATE LOBBY → INVITE FRIENDS**, затем **START GAME** и выбрать сцену.
- **Друзья:** принять приглашение в оверлее Steam (**Shift+Tab**) и ждать в главном меню.
- Гости появляются через 15 секунд после хоста (второй гость — через 30), чтобы никто не застрял друг в друге.
- Пока мод запущен, Steam может показывать, что вы играете в «Spacewar». Это нормально: мод использует бесплатное тестовое приложение Valve для сети.

### Сообщить об ошибке
Пришлите `ManhuntMP.log` из папки игры (по возможности от каждого игрока) и короткое видео в Телеграм-канал.
